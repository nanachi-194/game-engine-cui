# 迷路ゲームエンジン
## 名前
迷路用ゲームエンジン Ver 1.0.0

## 説明
　このゲームエンジンは簡単なCUIゲームを制作できるエンジンです。  
  もともとの状態であればただの迷路ゲームです。  
  制作するうえでLinux_conioを使用しているので、多分Linux OSでも動作すると思います、ただ検証と開発はWindows 11 64bit環境でやっているのでわかりません。  

  ### 遊び方
    １. game.exeがあるのと同じ階層にmap.mapファイルがあることを確認してください。  
    ２. 1が良ければgame.exeを起動してください。  
    ３. ゲームの移動は、wが上、aが左、sが下、dが右の移動になります、強制終了はqです。  
    ４. ゲームは自機以外すべて数字で表示されます、1が壁（移動不可）、2がゲームクリア、3が4を開ける鍵、  
      4が3が無いと開かない扉、5が6を開ける鍵、6が5が無いと開かない扉、7が次のマップに進む階段です。  

  ### 仕様
 　　map.mapの中身はすべて数字です、プログラムを見るとわかりますがリストでマップを読み込んでいるので.mapの中身をそのリストに合わせて書く必要があいります。
  今回の場合は9x10x4で書かれたマップをを2個書いています。中身を簡単に書き換えれるので書き換えながら遊んでみてください、また付属されている.pyファイルはその.mapを簡単に制作、書き換えできるものです。
  簡単に作れますが、9x10x4のマップを1個作るものなので、別でファイルを保存し中身をコピーしてmap.mapに書き込むのがおすすめです。

  ### 動作環境
  　1026/10/21時点の検証  
    OS. Windows 11 64bit 25H2  
    RAM. 8GB
